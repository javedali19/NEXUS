# Platform Integration Guide & Schema Specification

## 1. Integration Core Philosophy

This platform exposes a unified integration interface. Any event generated by ERP, CRM, or AI Communications is normalized into a standard platform event format and emitted via the **Transactional Outbox Engine**.

---

## 3. Module Event Taxonomy

### Customer & Identity Events
- `com.platform.customer.created`: Fired when a new shared customer profile is provisioned.
- `com.platform.customer.updated`: Fired when customer contact or account attributes change.

### CRM Events
- `com.platform.crm.lead.created`: New sales prospect created.
- `com.platform.crm.deal.stage_changed`: Deal advanced through pipeline stages.
- `com.platform.crm.lead.converted`: Lead converted into active customer identity.

### ERP Events
- `com.platform.erp.invoice.created`: Invoice issued to customer.
- `com.platform.erp.invoice.paid`: Payment posted against invoice balance.
- `com.platform.erp.order.fulfilled`: ERP sales order fulfilled.

### AI Communications Events
- `com.platform.aicomms.call.completed`: Telephony / voice call completed with AI transcription.
- `com.platform.aicomms.message.received`: Omnichannel inbound SMS / Email / Chat message.
- `com.platform.aicomms.sentiment.analyzed`: AI sentiment classification updated on shared timeline.

### Workflow & System Events
- `com.platform.workflow.triggered`: Automated cross-module workflow instance started.
- `com.platform.workflow.step_completed`: Individual workflow step completed.
- `com.platform.audit.logged`: System audit action recorded.

## 4. Webhook Dispatch & Security Protocols

External consumers can subscribe to platform webhooks.

### Webhook Signature Verification
Webhooks contain a custom signature header (`X-Platform-Signature`) computed as HMAC-SHA256 over the payload using the tenant's webhook signing secret.

```
X-Platform-Signature: t=1758532500,v1=9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08
```

## 5. Async Worker Integration (Cloud Tasks)

Background tasks (e.g. AI transcription summary generation, document parsing, ERP tax calculations) are dispatched to Google Cloud Tasks queues.

### Cloud Tasks Request Format
- **Target URL**: `https://worker.<region>.<project_id>.run.app/tasks/process`
- **Headers**:
  - `Content-Type: application/json`
  - `X-CloudTasks-QueueName: platform-background-tasks`
  - `X-Tenant-ID: <tenant_uuid>`
